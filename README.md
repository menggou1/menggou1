## How I Build · 做事方式

**01 / 从问题出发** — 先弄清楚使用场景，再决定需要哪些功能。

**02 / 先做小，再完善** — 从可用的版本开始，在实际使用中发现和打磨细节。

**03 / 保持清晰** — 整理页面结构，明确操作反馈，减少不必要的步骤。

**04 / 边做边学** — 把每个项目当作一次练习，也留下一份可以回看的记录。
